Full-stack SaaS başlangıç şablonu. React, FastAPI ve PostgreSQL ile geliştirilmiş; JWT tabanlı kimlik doğrulama sistemi içerir.

## Ne İş Yapar? / What Does It Do?

Kullanıcıların hesap oluşturabileceği, giriş yapabileceği ve profilini yönetebileceği bir web uygulaması. Yeni bir SaaS ürünü geliştirirken başlangıç noktası olarak kullanılabilecek şekilde tasarlandı.

A web application where users can register, log in, and manage their profile. Designed as a starting point for building new SaaS products.

## Özellikler / Features

- 🔐 Kayıt, giriş ve çıkış — JWT token tabanlı / Register, login, logout — JWT based
- 🛡️ Korumalı sayfalar — token olmadan erişilemiyor / Protected routes — inaccessible without token
- 📊 Dashboard — kullanıcı bilgisi ve metrikler / User info and metrics
- ⚙️ Ayarlar — profil ve şifre güncelleme / Settings — profile and password update
- ☁️ Render üzerinde canlı deploy / Live deployment on Render

## Teknoloji Yığını / Tech Stack
